# Conquering of Canaan — official Windows releases

This public repository is the official binaries-only download and automatic-update channel for **Conquering of Canaan**, a Biblical-world real-time strategy game by Vexona Studios.

## Install

Open the [latest release](https://github.com/vexonastudios/conquering-canaan-releases/releases/latest) and download **ConqueringOfCanaan-Setup.exe**. It contains the complete Windows game. The standalone executable and checksum assets are used internally by the automatic updater.

LAN and single-player play do not require an internet connection. Installed games check this channel for newer numbered releases when launched.

Current Alpha installers are not Authenticode-signed, so Windows may show an Unknown publisher or SmartScreen warning. Confirm that the installer came from this repository.

Source development is maintained separately in the Vexona Studios source repository.
